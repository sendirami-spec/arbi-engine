# Arbi-Engine (لغة قرش - Qarsh)

مرحباً بك في مستودع **Arbi-Engine**، الموطن الرسمي للغة البرمجة **"قرش" (Qarsh)**.

---

## 📖 نظرة عامة (Overview)
لغة "قرش" هي لغة برمجة طموحة تهدف إلى دمج البساطة مع القوة في المعالجة. تم تصميم هذا المستودع ليكون بيئة الاختبار والتطوير الأساسية للمحرك البرمجي الخاص باللغة.

**Qarsh** is an ambitious programming language designed to balance simplicity and processing power. This repository serves as the core development and testing environment for the language engine.

---

## 🚀 المميزات (Features)
- **بساطة الإسناد:** قواعد نحوية واضحة تعتمد على علاقة المسند والمسند إليه.
- **سرعة الأداء:** محرك محسن للتعامل مع الأوامر البرمجية بكفاءة.
- **القابلية للتوسع:** مصممة لتكون نواة لمشاريع برمجية أكبر.
